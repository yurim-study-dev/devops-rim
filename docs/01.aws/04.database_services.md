# 1. 관계형 데이터베이스 서비스

## 1.1 Amazon RDS 및 Aurora

### 1.1.1 Amazon RDS (Relational Database Service)
- 관계형 데이터베이스의 설치, 패치, 백업 및 조정을 패치 및 백업 자동화로 관리해 주는 클라우드 DB 서비스.

### 1.1.2 Amazon Aurora
- 초고성능 및 내결함성을 제공하는 클라우드 네이티브 관계형 데이터베이스 엔진.
