# 1. Amazon EC2 컴퓨팅 인프라

## 1.1 EC2 인스턴스 및 AMI 개요

### 1.1.1 Amazon EC2 정의
- 안전하고 용량 조절이 가능한 가상 서버를 클라우드상에서 제공하는 컴퓨팅 서비스.

### 1.1.2 Amazon Machine Image (AMI)
- 인스턴스 기동 시 필요한 운영체제, 애플리케이션 서버, 설정 정보가 포함된 템플릿.

# 2. 서버리스 컴퓨팅 및 확장 옵션

## 2.1 AWS Lambda 및 이벤트 기반 아키텍처

### 2.1.1 AWS Lambda 개요
- 서버를 직접 프로비저닝하거나 관리하지 않고 코드 실행을 지원하는 이벤트 기반 무서버 컴퓨팅 서비스.
