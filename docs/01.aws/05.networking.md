# 1. Amazon VPC 기본 인프라

## 1.1 VPC 개념 및 IP 주소 체계

### 1.1.1 Amazon VPC (Virtual Private Cloud)
- 사용자의 계정 전용으로 분리된 가상 네트워크 격리 영역.

## 1.2 서브넷 및 라우팅 테이블

### 1.2.1 서브넷 (Subnet)
- VPC IP 주소 범위를 분할하여 가용 영역에 할당한 네트워크 영역.

# 2. 네트워크 보안 및 통제

## 2.1 보안 그룹 및 Network ACL

### 2.1.1 보안 그룹 (Security Group)
- EC2 인스턴스 수준에서 트래픽을 제어하는 상태 저장 방식(Stateful)의 가상 방화벽.
