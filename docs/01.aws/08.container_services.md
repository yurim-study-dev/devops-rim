# 1. 컨테이너 개요 및 오케스트레이션

## 1.1 컨테이너 기술 및 도커

### 1.1.1 컨테이너 개념
- 애플리케이션과 실행 환경을 하나로 격리하여 패키징하는 이식성 높은 프로세스 실행 기술.

## 1.2 Amazon ECS 및 EKS

### 1.2.1 Amazon ECS (Elastic Container Service)
- AWS의 높은 이식성을 자랑하는 컨테이너 오케스트레이션 및 관리 서비스.
