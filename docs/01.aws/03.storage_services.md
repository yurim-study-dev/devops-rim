# 1. 블록 및 객체 스토리지 인프라

## 1.1 Amazon EBS 블록 스토리지

### 1.1.1 EBS (Elastic Block Store) 개요
- Amazon EC2 인스턴스에 연결하여 사용하는 영속적 블록 레벨 저장 장치.

## 1.2 Amazon S3 객체 스토리지

### 1.2.1 S3 (Simple Storage Service) 개요
- 데이터와 메타데이터를 객체 단위로 저장하는 무제한 확장 가능한 클라우드 객체 스토리지.

# 2. 파일 스토리지 및 데이터 이동

## 2.1 Amazon EFS 네트워크 파일 시스템

### 2.1.1 EFS (Elastic File System) 개요
- 여러 EC2 인스턴스에서 동시에 공유하여 사용할 수 있는 확장 가능한 관리형 파일 시스템.
