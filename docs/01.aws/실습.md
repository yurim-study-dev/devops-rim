## 6.2 구동 중인 Java 프로세스 조회 및 중지
- 실행 중인 Java 프로세스 식별자(PID) 조회 및 프로세스 중지

```sh
# 실행중인 자바 프로세스 ID 확인
pgrep -f java

# 자바 프로세스 중지
kill -9 <PID>
```

# 7. 커널 패킷 포워딩 설정 및 트래픽 패킷 덤프

## 7.1 IPv4 패킷 포워딩 활성화 및 커널 영구 설정
- 커널 매개변수(ip_forward)를 1로 지정하여 포워딩 활성화 및 설정 반영

```sh
# 패킷 포워딩 기능 확인
sudo sysctl net.ipv4.ip_forward
```

```sh
# 패킷 포워딩 활성화
sudo sysctl -w net.ipv4.ip_forward=1
```

```sh
# 재부팅 후에도 유지되도록 설정 파일에 반영
echo "net.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/ip_forward.conf
```

## 7.2 80번 네트워크 포트 실시간 패킷 캡처 (tcpdump)
- 80번 포트 네트워크 패킷 흐름 캡처

```sh
sudo tcpdump -i any port 80 -n
```
